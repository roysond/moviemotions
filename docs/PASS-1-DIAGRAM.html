why · cost to learnKarate Kid never surfaced for "inspiring" — the film is, the text isn't. So a model reads each overview and writes how it feels, at write time.

First prompt put "coming of age" on 15 of 20 films: examples in a prompt become the answer space. Banning "tense" produced "tension" six times — a ban removes the word, not the pull toward it. And enrichment still couldn't fix Karate Kid, which proved the real need was a narrative source.

Embed

pass 0Nova 2 @ 1024dunchanged — the model was already right
1 · semanticembed every sentence, cut where meaning shiftsthreshold = 80th percentile of THIS plot's own shifts
2 · recursiveover 900 chars → cut again at its own biggest shiftthe cap decides whether; meaning decides where
3 · overlapstitch only the 39 size-forced seamsnot at semantic seams — meaning genuinely changed there
4 · contextual header"Finding Nemo (2003). ...his worrisome father Marlin..."prepended AFTER boundaries are set · zero extra model calls
why · cost to learnOne vector over 4,000 chars averages 27 scenes into mush.

Percentile, not a fixed threshold — Nova's space is narrow (unrelated text ≈0.64), so "split below 0.8" means something different in every document and dies on a model swap.

The header is the breakthrough: a chunk saying "Nemo swims to a speedboat and is captured" has no father, no son, no search. Chunking preserves events and destroys relationships. This alone took case 1 from 1/3 to 3/3.

why · cost to learnFive measured failures, none found by reading code.

Adding 136 plot chunks changed nothing — scores identical to 4 decimals. DISTINCT ON collapsed to one chunk per film in SQL, and a 120-char mood blurb beat its own film's 600-char scene every time. An optimisation is only safe if it discards what the downstream component wouldn't have wanted.

Widening the pool didn't help either: short abstract chunks win on concentration, not relevance. Chunk length is a confound — compare like with like.

Reranker host: 3 AWS walls (Marketplace, region, IAM) → a gateway. Fine for public data, a BAA liability for PHI.
