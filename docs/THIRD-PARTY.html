It's what a compliance or privacy team asks for when someone says “can we ship this?” Without it, that question means re-reading five sets of terms and hoping you remember which tier you picked.

3 · What this table already tells us

Four things fall straight out of the rows above, before anyone writes a line of code.

Four services will receive personal data

IP address to geolocation; latitude and longitude to weather and showtimes; raw user queries to the LLM provider and LangSmith. That is a real data-processing footprint — it needs consent, minimisation, and a retention decision, not an afterthought.

LangSmith is the easiest one to get wrong

Its entire purpose is capturing everything that happened, which by default includes the user's words. Whatever scrubbing rule we choose has to be set deliberately, not inherited.

Commercialising today is blocked in four places

TMDB Developer, OMDb free, Open-Meteo free, and the showtimes sandbox are all non-commercial. Correct for a learning build — and it means “can we ship this?” has a documented one-sentence answer.

Two attributions are already owed

TMDB requires its logo plus a specific notice. Wikipedia text is CC BY-SA 4.0. Both belong in an About or Credits section from the first release, not retrofitted later.

4 · Where the secrets live

Every key in this register lives in one place: a .env file at the repository root, gitignored before the first commit.
  • Never in code, in a notebook, or in a config file that gets committed
  • One name per service — TMDB_API_KEY, LLM_API_KEY
  • .env.example is committed — same key names, no values — so anyone cloning the repo knows what they need without ever seeing a secret

5 · Review triggers

Revisit this file when any of these happen:
  • A new external service is added
  • A tier changes, or a free tier's limits change
  • The project's purpose shifts toward revenue — then every “No” in the commercial column becomes a task
  • Any new field of user data starts being sent outward
  • Every six months regardless — terms change quietly
