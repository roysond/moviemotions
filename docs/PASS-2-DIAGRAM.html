Pass 2 · the pipeline becomes a loop

One component changed shape — and everything downstream had to grow to hold it

Pass 1 deepened all eight components without adding one. Pass 2 does the opposite: seven components barely move, and Reason stops being a straight line. A single LLM call becomes a graph that decides, acts, looks at what came back, and decides again. Retrieval recall is unchanged at 86.2% — this pass bought a different kind of correctness.

Query expansion came free. Pipeline RAG bolts on an extra LLM call to rewrite thin queries; here choosing the query argument is the rewrite. "cosy" scored 0.08 and ranked noise; "a warm gentle feel-good film for a rainy evening" scored 0.37. Same corpus, 4× the signal.

The cause was mine: my docstring's own example demonstrated compression while the prose asked for expansion. Examples override instructions.

The interrupt's first live run cost six wasted cycles arguing with a display bug — textwrap.wrap() silently ate the newlines the model had correctly inserted. A review surface that misrepresents the draft is worse than no review.

Only one metric gets an LLM. Tool choice and grounding have exact tests, so they are deterministic, free and cannot drift — the same rule as the search tool, one level up.

Faithfulness scoring 0.44 looked like a failure and was the most useful number of the pass: it caught that every reason the model gave was invented, while the exact metrics said 6/6 because they only check which films were named.

Three lessons that outlive this codebase

Layered blindness
Exact metrics missed the fake reasons. The judge caught those. The judge could never have caught Terminator 2 at 0.536 — a human did. Each layer sees the one below's blind spot.
Certainty ≠ correctness
Both worst answers scored above every threshold. A score says how sure the machine is, never whether it is right.
Reproduce first
A 10-point jump that never came back. Write the prediction before the run, and never author the explanation for the number you preferred.
